# Modular relations with designed redundancy, d=8, complete cube, 3 seeds

`modular_relations_d8`  ·  d = 8  ·  768 cells  ·  4 outputs  ·  complete (all 2**d coalitions)

## What one player is

one of 8 groups of relation facts: A and its replica teach the same relation, B and C teach distinct relations, four groups are distractors

| # | player |
|---:|---|
| 0 | `group_0` |
| 1 | `group_1` |
| 2 | `group_2` |
| 3 | `group_3` |
| 4 | `group_4` |
| 5 | `group_5` |
| 6 | `group_6` |
| 7 | `group_7` |

## What `v(S)` is

mean log probability of the correct answer for each of four query families

- **Evidence type:** retraining
- **Learner:** tiny neural learner that estimates seven relation-specific 11x11 conditional tables from modular affine facts; evaluation composes the learned stochastic transition matrices; retrained per coalition for each of 3 initialisation seeds
- **Cost of one coalition:** median 0.2 s per cell (runtime_seconds)
- **Outputs:** 4 query families: atomic_additive_ABC, pair_AB, redundant_A, triple_ABC
- **Secondary channel:** exact_answer_accuracy for the same 4 families
- **Licence:** synthetic relation data generated by this project

## Measured cells

- coalition sizes 0–8; 256 distinct coalitions of the 256 possible
- splits: `fit` 768
- learner seeds: 31 (256 cells), 43 (256 cells), 59 (256 cells)
- same-seed noise replicates: 0
- seed-to-seed spread (output 0): mean per-coalition SD 0.00418379, max 0.0114742 over 3 seeds; this is the retraining-noise scale for the cube

## Caveats

- the redundancy result (-2.401 nats) is a property of the redundant_A query family; the other three families are controls
- the learner is small and converged, so this cube is much cleaner than the transformer cubes and should not be used to argue about deep-learning noise

## Conventions

- bit convention: masks[n] has bit i (value 2**i) set iff player i is in the coalition; player 0 is the least significant bit
