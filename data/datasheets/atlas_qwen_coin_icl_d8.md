## What `v(S)` is

negative mean query NLL (higher is better)

- **Evidence type:** frozen-inference
- **Learner:** frozen Qwen forward pass; the coalition selects in-context examples of a generated coin-flip benchmark, no weights change
- **Cost of one coalition:** one frozen forward pass per evaluation item
- **Outputs:** 1: utility
- **Secondary channel:** secondary_metric as stored by the source (accuracy where defined)
- **Licence:** underlying public dataset licence applies (UCI HAR, California housing, AG News, MovieLens 100k, SST-2 as appropriate); utilities generated by this project

## Measured cells

- coalition sizes 0–8; 256 distinct coalitions of the 256 possible
- splits: `fit` 256
- learner seeds: not applicable (deterministic fit)
- same-seed noise replicates: 0
- deterministic refit with no learner seed: retraining noise is zero by construction, so any surrogate error on this cube is approximation error

## Caveats

- FROZEN INFERENCE, NOT RETRAINING: the coalition changes the prompt, not the weights; do not pool this cube with retraining cubes when making a claim about data attribution
- single deterministic fit: no learner seed and therefore no noise ceiling

## Conventions

- bit convention: masks[n] has bit i (value 2**i) set iff player i is in the coalition; player 0 is the least significant bit
- convention evidence: the atlas generator indexes with ((mask >> arange(d)) & 1), i.e. least-significant bit is group 0, the same convention as this suite
